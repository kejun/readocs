# SD 扩展存储与全量离线同步

0.2.7 起，PaperDIY 使用已安装、可写且空间足够的 SD 卡存放索引、同步进度和正文。片内缓存保留为无卡时的回退。安装或更换卡后重新启动；同步期间不切换存储后端。

## 挂载和数据范围

- 固定驱动的 PaperDIY SD 引脚为 SCLK 39、MOSI 38、MISO 40、CS 47，来自 M5Unified 板级引脚表，采用 ESP-IDF 5.5.5 SDSPI / FATFS，10 MHz。
- 挂载失败不会格式化、重新分区或删除卡上文件。首次使用只在 `/readocs/<本机标识>/` 内创建缓存；不同终端的目录分开。
- 启动时检查挂载、目录可写性和容量。FAT 长文件名使用堆缓冲，缓存对象仍以完整 SHA-256 命名。
- SD 与片内索引分别使用 `readocs_sd` 与原 `readocs` NVS 命名空间。首次使用 SD 时复制片内已有正文并校验，再发布 SD 索引；失败回退到片内。原片内文件和指针保留，Wi-Fi、绑定、字体设置、阅读锚点及刷新中断标记继续使用原设置。
- 容量使用 64 位字节数，支持大于 4 GiB 的卡。`status` 提供 `sd_available`、`external_cache`、`sd_total_bytes`、`sd_free_bytes`、`sd_reserved_bytes`、`sync_pending` 与已缓存正文数量。

## 同步和空间策略

无卡时保留每来源前 5 篇以及当前/排队打开正文的策略。使用 SD 时保留全部正文，不再按 5 篇配额清除引用。每次同步读取实际剩余空间，每篇下载前再按引用中真实字节数检查：扣除 8 MiB 余量后，至少还能容纳正文大小的两倍。余量留给索引、进度提交及文件系统操作；停止正文预取后仍允许用余量提交最后一批索引。不会按标称 16G 直接假定可用。

完整同步按 120 秒联网预算分批执行，每 12 个目录项提交已校验的缓存索引及进度。还有未下载内容且本批有实际进展时自动继续；上游明确返回暂无正文时保留目录并等待清单版本更新，使用正常检查周期，不因这些条目每分钟重试。空间不足时保存已有成果并提示，不删除原有可读内容。重启后不会仅因剩余空间低于下载余量而放弃已有 SD 缓存，仍检查目录可写性和索引，停止增加新正文。每个正文沿用分块长度、分块 SHA-256、整体 SHA-256、格式及大小校验，临时文件完整写入、同步和验证后才发布。

进度同时保存缓存快照与目标快照，接续时跳过已经取得的对应版本。若目录未变而正文版本/清单 ETag 改变，会重新检查进度中的目标，避免用旧进度确认尚未取得的新正文。SD 缓存损坏或缺失的正文会在联网任务中重新取得；按键唤醒时仅验证索引，不集中读取所有正文。实际打开文件时仍校验其完整哈希，已验证对象在本次运行内使用有界记录避免每批反复读取。

目录仍限制 512 KiB，单篇正文仍限制 300 KiB / 500 块。扩展卡提高离线正文容量，不取消协议、内存或排版边界。上游尚未抓取成功或无权限的文档无法凭空下载。代理也保留 RSS 当前目录内全部 50 篇正文，取消旧的 20 篇正文配额；旧配额留下的当前条目缺口会触发一次非条件抓取，补齐后恢复 ETag / Last-Modified 检查。滚出源的历史缺口不会使条件检查永久失效。

## 传输路径

可通过 USB `local_proxy` 配置同一台已绑定代理的局域网 HTTPS 地址、CA 证书和证书服务名（可选 `name`）。不会更换设备凭据或公网地址。请求优先使用此配置；GET 连接/读取失败时先重建一次局域网连接，处理保存进度期间代理关闭空闲连接的情况，再失败则在本批内回退原公网地址。不会自动重放 POST、跳过证书验证或跟随重定向。更换绑定时清除旧局域网配置。局域网地址变化后可重新配置，或将 `server` 设为空清除。

批量 SD 同步在实际联网期间使用 `WIFI_PS_NONE`，结束后仍关闭 Wi-Fi，空闲轻睡策略不变。局域网底层等待设为 2.5 秒、公网 SD 传输为 15 秒，整批仍受联网预算及进度检查约束。`status` 可查看 `wifi_rssi`、`wifi_power_save`、`local_proxy_configured` 和 `local_proxy_fallback`。这不替代装卡后的整板能耗测量。

## 阅读、刷新与验证

SD 只改变缓存后端和预取范围。Noto Sans SC Medium 500、字簇与阅读锚点、同屏选择行局刷、正文局刷、P2 质量清理、15 秒轻睡交互窗口均遵守[刷新维护基线](device-refresh.md)。下载写入和整库修复发生在联网任务中，不在快速绘制路径重新挂载 SD；实际打开文章仍读取并校验其正文。装卡后的整板电流尚需另测。

`tests/test_sd_sync.py` 执行实际同步和下载函数，覆盖无卡配额、全部缓存、跨批接续且不重复遍历前缀、304 保留全量正文、正文版本更新、缺失缓存修复、容量大于 4 GiB、空间不足后的进度保存和上游暂无正文时不持续自重试。`tests/test_firmware_transport.py` 执行实际 HTTP 请求函数，覆盖局域网 GET 重建连接、公网回退、POST 不重放及超限响应不重试。原缓存提交、GC、来源、输入、睡眠及刷新测试继续运行。
